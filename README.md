# ai-news — 매일 AI 소식을 모아 노션 지식창고에 쌓는다

    bash ~/ai-news/daily.sh              # 오늘 + 최근 3일 미처리분
    bash ~/ai-news/daily.sh 2026-08-17   # 그 날짜만 다시

| 파일 | 무엇 |
|---|---|
| `sources.json` | 수집 출처 목록. 출처를 늘리거나 줄이려면 **여기만** 고친다 |
| `collect.py` | 긁어서 파일로 떨군다. LLM 을 부르지 않는다 |
| `pick.py` | 150건을 브리핑 입력 + 정식 후보 12건으로 가른다 |
| `ARCHIVE.md` | 노션에 어떻게 넣는지. `claude -p` 가 이걸 읽고 실행한다 |
| `verify_day.py` | 실제로 들어갔는지 판정. 통과해야 `.done` 이 찍힌다 |
| `daily.sh` | 위를 순서대로 돌린다. 크론 진입점 |

## 노션 어디에 쌓이나

- 원문 정본 → 📄 Source Library `38c2eeda-241b-400f-a385-8b68b096a08a`
- 정리본 → 🤖 클로드·AI 자동화 지식 `bd5ed794-314c-4aaf-b932-d96856735e96` (`원본자료` 릴레이션으로 원문과 연결)
- 하루치 브리핑 → 📰 **AI 뉴스 브리핑 DB** `15f83675-eaba-4235-b459-537dde57bc74` (📚 도서관 하위, 다른 서고와 같은 층위. 날짜·건수로 정렬된다)

## 실측으로 얻은 것 (2026-08-18)

- **Jina Reader 는 파이썬 클라이언트를 403 으로 막는다.** urllib·curl_cffi 둘 다 실패, `curl` 바이너리만 200
- **anthropic.com 은 RSS 를 폐지했다.** 구글뉴스 `site:` 검색으로 대체
- **Reddit `.json` 은 WAF 403, `.rss` 만 통한다.** 그마저 병렬로 때리면 통째로 429 → 순차 5초 간격
- **X 는 `created_at` 포맷이 오락가락한다.** 트윗 ID(snowflake)에서 시각을 뽑는 게 정확
- **본문 확보 예산을 점수순으로만 쓰면 X 가 다 먹는다.** 출처당 4건 상한을 먼저 건다
